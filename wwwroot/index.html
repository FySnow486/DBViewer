开始探索

左侧选择数据表，查看字段定义和相关外键。切换「ER 关系图」查看整个数据库的关系。

通过「新建连接」连接 PostgreSQL、MySQL、SQL Server 或 SQLite。建议使用仅有元数据读取权限的账号。

按 / 搜索表；ER 图支持拖动、缩放和双击查看；「导出结构」下载当前数据库的 JSON 结构文档。

当前版本面向本机使用，不含多用户身份认证。SQLite 本身没有标准字段注释，相关注释显示为空。
